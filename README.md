# Blanche Sebahoun — Sage-femme

Landing page pour le cabinet de Blanche Sebahoun, sage-femme libérale à Paris 16e.

## Contenu

- `index.html` — page unique (HTML/CSS/JS vanilla, sans dépendance de build)

## Développement local

Servir le dossier avec n'importe quel serveur statique, par exemple :

```bash
python3 -m http.server 4173
```

Puis ouvrir http://localhost:4173

## Image du hero

La page référence une image `hero.jpg` (photo du cabinet) à placer à la racine du
projet, à côté de `index.html`. Tant qu'elle est absente, un visuel de secours
s'affiche automatiquement à sa place.
